# MediTrack – Healthcare Database Management System

## Project Overview

MediTrack is an Oracle SQL-based database management project designed to manage healthcare information, including patient records, doctor details, departments, and appointments.

The project focuses on organizing healthcare data and performing SQL-based analysis to understand appointment patterns and patient waiting times.

## Database Tables

- **DEPARTMENTS** – Stores department information.
- **PATIENTS** – Stores patient details.
- **DOCTORS** – Stores doctor information.
- **APPOINTMENTS** – Manages appointment schedules and status.

## Technologies Used

- Oracle SQL
- SQL*Plus
- Oracle SQL Developer

## SQL Concepts Applied

- DDL and DML
- Primary Keys and Foreign Keys
- Constraints
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Date Functions
- Data Analysis

## Key Analysis

- Department-wise appointment analysis
- Doctor-wise waiting time analysis
- Average patient waiting time
- Appointment status analysis

## Project Objective

To strengthen database management and SQL query-writing skills through a practical healthcare database project.
